# 大阪芸術大学マッチング

芸大生だけの禁断マッチング。
YESを押せば運命、NOなら強制退室。
そして必ず「塚本邦彦」に出会う。
このREADMEは真面目に読まなくていい。

## はじめかた (たぶん)

```
npm install
npm run dev
```

## ビルド (世界征服用)

```
npm run build
```

## GitHub Pages (舞台の上に出す)

- [vite.config.js](vite.config.js) の `base` を `/<リポジトリ名>/` に合わせる
- `npm run build` で生まれる `dist` をPagesへ供物として捧げる

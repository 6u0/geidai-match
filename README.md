## 🎨 作品コンセプト：『決定論的邂逅 ― アルゴリズムの専制と遍在する権威』

本プロジェクトは、現代の人間関係を規定する「マッチング・アルゴリズム」の欺瞞性と、教育機関における「権威の象徴」を批判的に掛け合わせた、インタラクティブなメディア・アート作品です。

### 1. 垂直的権威の水平化と「非日常感」の創出
本来、学生にとって「学長」とは式典の壇上や肖像画の中にのみ存在する、垂直的で不可侵な権威の象徴です。本作は、マッチングアプリという極めて日常的、かつ卑俗な「俗」のプラットフォームに、大学の頂点である「聖」なる存在を強制召喚します。
スワイプという日常動作の果てに、突如として学長（のAI表象）と一対一でマッチングする**「エクストリームな非日常体験」**は、学内における既存の階層構造を一時的に解体し、権威の在り方を再定義する試みです。

### 2. アルゴリズムによる「自由」の風刺
ユーザーがいかなる選択を繰り返したとしても、最終的に「学長」という単一の表象に収束するシステムは、私たちの自由意志が実はプラットフォームのコードによって設計・制限されているという現代社会の決定論的な帰結を皮肉っています。

### 3. バッタとしての実存
「ここは芸大、みなさんはバッタ」。この不可解なミームは、個性を求められながらも巨大なシステム（大学・社会）の一部として群生する学生たちの実存的状況を象徴しています。学長という絶対者とのマッチングは、バッタ（学生）がシステムそのものと対峙するメタ的な通過儀礼なのです。
